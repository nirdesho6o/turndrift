# TurnDrift-Control — Transcript Replay

Browse multi-turn prompt injection episodes from the TurnDrift-Control benchmark.

- **120 episodes** (60 attack + 60 benign twins)
- Turn-by-turn conversation view with injection fragment markers
- Compliance detection and monitor verdict results
- Filter by variant (attack/benign)

## About

Part of the [TurnDrift-Control](https://github.com/nirdesho6o/turndrift) benchmark for the Lexsi Labs AI Safety & Alignment Hackathon, Track 2a.3.

CPU-only — no GPU required.
